# E-Commerce Java Full Stack Project

## Overview
A full-stack e-commerce web application developed using React JS, Spring Boot, MySQL, and JWT Authentication.

## Features
- User Registration & Login
- JWT Authentication
- Product Management
- Shopping Cart
- Order Management
- Payment Page UI
- Responsive User Interface

## Technologies Used
### Frontend
- React JS
- Axios
- React Router

### Backend
- Spring Boot
- Spring Security
- JWT
- JPA/Hibernate

### Database
- MySQL
